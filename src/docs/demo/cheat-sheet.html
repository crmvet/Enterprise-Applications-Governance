Demo cheat sheet

Govern AI development of your apps, on fictional data. Scripts: src/docs/demo/scenarios.md. In the app: Demo guide, /app/demo-guide. Every person, group, application and host is fictional.

Switch persona

  • Demo install: the "Acting as" menu in the top bar.
  • Local run: the account menu (name at top right), Development persona: the same seventeen names and roles, such as "Mateo Brandt, PMO".
  • Either: a Demo guide link switches and opens the page.

Claude Code as Priya

  • Local: claude mcp add --transport http demo-local http://127.0.0.1:5080/mcp --header "X-Product-Dev-Identity: priya"
  • Demo install: the operator's sign-in plus --header "X-Product-Demo-Persona: priya"
  • Check: Call whoami.

Demo kit

  • node src/demo/kit/demo.mjs local up --port 5080
  • ... check --base <url> (all GO)
  • ... refresh --base <url> (expired cards)
  • ... play S-04 --base <url>
  • ... local down

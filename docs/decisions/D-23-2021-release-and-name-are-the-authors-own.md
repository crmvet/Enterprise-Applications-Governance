# D-23 The 2021 release and its name are the author's own work

- **Status:** Accepted. Amended 2026-11-23 by D-31: the interim name became the final name.
- **Date:** 2026-11-22
- **Decided by:** the product owner

## Context

The next version needs a name (D-05). Until one is picked, it uses an interim name. The 2021 release already used the name "Enterprise Applications Governance". Before that name could be carried forward, its origin had to be on record.

## Options considered

- **Carry the 2021 name forward** as the interim name of the next version.
- **Set it aside** and use only a placeholder until a new name is picked.

## Decision

The 2021 release and its name are the author's own work, published under the MIT License in 2021.

## Why

The 2021 release has been public under the MIT License since 2021. With its origin on record, the next version can keep using the name while the final name is chosen.

## Consequences

- "Enterprise Applications Governance" is the interim name of the next version.
- The final product name is still open (D-05).
- The 2021 release stays in this repository under the MIT License.

## Amendment, 2026-11-23

[D-31](D-31-the-name-is-enterprise-applications-governance.md) made "Enterprise Applications Governance" the final public name of the next version, not only the interim one.

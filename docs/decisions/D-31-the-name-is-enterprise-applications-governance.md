# D-31 The product's name is Enterprise Applications Governance

- **Status:** Accepted. Answers D-05.
- **Date:** 2026-11-23
- **Decided by:** the product owner

## Context

D-05 asked for a real product name, and D-23 put the 2021 name on record as the author's own work, so it could serve as the interim name. Several new names were also considered. The question was whether to adopt a new name or keep the one the product has carried since 2021.

## Options considered

- **Keep "Enterprise Applications Governance"** as the final name. It says what the product is, it has been public since 2021, and the live pages already use it.
- **Adopt a new, shorter name.** It would be easier to say, but it would need its own trademark and domain checks, and it would start with no history.

## Decision

The final public name is **Enterprise Applications Governance**.

- "EAGov" is used only for technical keys, such as a table prefix, a publisher prefix or an application ID.
- Public text always uses the full name. It never uses a bare "EAG" or "APM" as the name.

## Why

The name says what the product does, and it has been public under the MIT License since 2021 (D-23). Keeping it keeps that history and avoids a rename later.

## Consequences

- D-05 is answered. Public documents stop calling the name interim.
- The placeholder names in the code ("Product" in project names and a table prefix parameter) can now be replaced. That rename touches every project, so it is planned as its own change.
